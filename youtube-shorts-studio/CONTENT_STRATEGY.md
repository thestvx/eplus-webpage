# CONTENT STRATEGY

## Audience
Children 3–7 (primary). Parents (secondary, gatekeepers). Global-friendly / language-light.

## Format
YouTube Shorts, 15–60s, vertical (9:16), ultra-short hooks, high replay.

## Pillars (concept categories we cycle through)
1. Funny character mistakes (Flippy-driven)
2. Animals/each-other helping (Nana-driven)
3. Surprising transformations
4. Playful micro-adventures (Pip-driven)
5. Simple problem solving
6. Friendship & kindness beats
7. Curiosity & discovery
8. Music/rhythm moments (short, original melody hooks)
9. Visual comedy / cause-effect
10. Miniature adventures (scale play in Wonder Grove)

## Series-Ready Recursive Concepts
- **"Pip's Lost Hatchers"** — Pip loses/replaces a small thing each episode; object-of-the-week keeps identity fresh but format recognizable.
- **"A Tiny Help"** — a problem appears, someone helps; reinforcing kindness pillar.
- **"What's in the Box?/Bubble/Ball?"** — curiosity + reveal loop, excellent replay.

## Recurring Hooks Tactics
- First frame = big emotion + motion + question ("Whoa!").
- Fast 1-2s cold open before any title.
- End on a loop point back to the start.

## Monetization / Policy Guardrails
- 100% original assets and audio. No copyrighted songs/characters.
- No misleading thumbnails or deceptive metadata; no spam; real creative difference between episodes.
- Keep above the "reused/duplicated content" line by changing story, composition, and scene per episode.
- **Reminder:** monetization eligibility is determined by YouTube's current policies; we build to be eligible but never guarantee it.

## Content Library Structure
```
content/
  ideas/        # raw concepts
  scripts/      # Phase 2 scripts
  storyboards/  # Phase 3 storyboards
  production/   # in-progress assets + clips
  completed/    # finished QC-passed episodes
  published/    # episodes shipped to YouTube
```
Each episode has an `episode.json` metadata file.
